FOLLOW THE REQUEST

Three checks before you debug the prompt.

  1. AccessGET /v1/models. Is the exact model ID returned for your key?
  2. ProtocolConfirm Chat Completions support in the provider's model catalogue. Listing a model does not prove it supports every endpoint.
  3. Availability & creditCheck current model status and prepaid balance. A model list is not an uptime test.
